Dos necesidades de Recursos Humanos

Desarrollo herramientas Python para el envío de nóminas cifradas y para cuadrar nóminas. La corporativa realiza envíos y algunos colegios los gestionan directamente con estas utilidades. Coordino las mejoras con Recursos Humanos.

Volumen y periodicidad

Se han enviado más de diez mil nóminas de forma acumulada durante más de medio año. Se realiza una ejecución mensual por colegio, con una media aproximada de ochenta nóminas por colegio y mes. Cifras facilitadas por el titular.

Antes y después: el envío mensual

El proceso manual partía de un PDF con todas las nóminas: había que separarlas una a una y enviar cada documento por correo individualmente. La utilidad automatiza ese trabajo repetitivo en la ejecución mensual.

  1. PDF con el lote mensual de nóminas
  2. Separación de los documentos individuales
  3. Preparación de las nóminas cifradas
  4. Envío individual a cada destinatario

Antes y después: el comparador

Antes había que trasladar manualmente a Excel los datos de cada nómina. El comparador automatiza esa incorporación de información y elimina ese paso de transcripción manual.

Mi aportación

Me coordino con Recursos Humanos para introducir cambios y mejoras en las utilidades. Mi trabajo da servicio a RR. HH. de la corporativa y de los centros, con el objetivo de agilizar procesos y facilitar el uso de las herramientas.

Alcance de esta presentación

La descripción es funcional: no se publican nóminas, destinatarios, claves ni detalles operativos internos. El cifrado forma parte de la utilidad descrita; este caso no constituye una auditoría de seguridad ni una certificación de cumplimiento.
