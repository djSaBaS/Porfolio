El problema

Limitar cuántas veces puede seleccionarse una opción de un formulario y facilitar la administración de sus reglas desde WordPress.

Por qué desarrollar una solución propia

Evaluamos plugins existentes: muchas alternativas eran de pago y las gratuitas no cubrían todas nuestras necesidades. Decidimos desarrollar una solución propia para adaptar el control de límites a los formularios que necesitábamos. Mi aportación incluye el desarrollo personal de una versión similar a la utilizada en la empresa, cuyo repositorio público permite revisar su funcionamiento.

La solución documentada

  • Integración con Contact Form 7 y gestión de reglas desde el editor de formularios.
  • Configuración, ampliación y eliminación de límites para impedir nuevas selecciones cuando se alcanza la disponibilidad definida.
  • Persistencia de reglas y contadores, reinicios periódicos y comprobación de disponibilidad mediante AJAX.
  • Evolución del esquema y documentación de uso para la administración.

Evidencias para revisar

El README documenta pruebas de creación de límites, validación administrativa, permisos y nonce, además de un flujo de GitHub Actions. El enlace permite consultar el código y su historial. La existencia de estas pruebas no equivale a una auditoría independiente ni demuestra por sí sola la resolución de todos los escenarios de concurrencia.
