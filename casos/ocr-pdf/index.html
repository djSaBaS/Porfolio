OCR para PDF

AUTOMATIZACIÓN CON CÓDIGO PÚBLICO

Repositorio público

PythonPyQt6OCRmyPDFTesseract

El problema

Hacer consultable el texto de documentos escaneados y acercar las opciones de procesamiento OCR a una interfaz de escritorio.

La solución documentada

  • Interfaz Python con PyQt6, selección de idiomas y opciones de rotación, enderezado y limpieza.
  • Flujo principal con OCRmyPDF y alternativa con Tesseract.
  • Tratamiento del progreso y de la disponibilidad de herramientas auxiliares, según la documentación del repositorio.

Evidencias para revisar

El repositorio documenta pruebas automatizadas con pytest y un flujo de GitHub Actions para utilidades críticas. Se presenta como integración y automatización de herramientas OCR, sin atribuir entrenamiento propio de modelos ni métricas de precisión no medidas.
